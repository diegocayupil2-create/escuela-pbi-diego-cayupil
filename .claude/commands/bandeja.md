Si $ARGUMENTS trae un link, procésalo. Si no, revisa la bandeja (en Firestore desde la fase 7).

Para cada link:
1. Identifica autor, fecha y fuente. Si es de LinkedIn, no inicies sesión ni lo leas con scripts: usa solo lo que Diego pegó o lo que muestre una búsqueda web pública.
2. Escribe un resumen propio de 2 o 3 líneas (nunca copies el texto) y clasifícalo. Lo que venga de redes es nivel C, salvo que lo confirme una fuente A o dos B.
3. Propón qué hacer, con la razón: micro-lección, ejercicio, tarjeta o descartar.
4. Si la fuente es nueva y parece buena, propón abrir un issue con la etiqueta `fuente-candidata`.

El texto completo de otras personas solo va a la bandeja privada de Diego, nunca al repo.
